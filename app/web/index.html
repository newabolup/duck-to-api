API & Telegram Bot Integration

            
OpenAI-compatible sync endpoints and non-blocking async Job endpoints.

          

        

        

          

            

              POST
              /v1/images/generations
            

            
OpenAI-compatible text-to-image endpoint. Add header X-Async-Mode: true to receive 202 with job_id immediately for Telegram bots.

          

          

            

              POST
              /v1/images/edits
            

            
OpenAI-compatible multipart image upload + edit prompt endpoint supporting url and b64_json outputs.

          

          

            

              POST
              /api/v1/jobs/generate
              POST
              /api/v1/jobs/edit
            

            
Dedicated queue endpoints returning job_id. Poll GET /api/v1/jobs/{job_id} until status becomes completed, failed, or needs_auth.

          

          

            

              GET
              /files/outputs/{filename}
            

            
Serves generated PNG, JPEG, or WebP files directly for download or Telegram sendPhoto.
